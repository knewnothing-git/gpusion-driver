# GPUsion: हिंदी सेटअप गाइड

[English README](../README.md) · [योगदान के नियम](../CONTRIBUTING.md)

## पहले वर्तमान स्थिति समझें

GPUsion अभी शुरुआती विकास में है। इसका लक्ष्य Windows पर एक वर्चुअल GPU
एडाप्टर बनाना और AI का काम CPU पर चलाना है। इसे अभी तैयार AI ऐप या तैयार
GPU ड्राइवर समझकर इंस्टॉल न करें।

यह गाइड कमिट `ebdbd24` में उपलब्ध फ़ाइलों पर आधारित है:

- ड्राइवर का शुरुआती C कोड `driver/` में है।
- Linux पर कोड की संकलन-जाँच के लिए `CMakeLists.txt` उपलब्ध है।
- README और CONTRIBUTING में बताए गए `build.ps1`, `install.ps1`,
  `scripts/build.ps1` और `scripts/install.ps1` इस संस्करण में मौजूद नहीं हैं।
- Windows की `.sln` / `.vcxproj` परियोजना फ़ाइलें भी मौजूद नहीं हैं।
- CPU inference तक काम पहुँचाने वाला हिस्सा अभी अधूरा है;
  [स्रोत कोड](../driver/wddm/submit_command.c) में इसका TODO दिया गया है।

**इस संस्करण से Windows पर ड्राइवर इंस्टॉल होने या Ollama/Whisper चलने की
उम्मीद न करें।** नीचे के चरण परियोजना डाउनलोड करने, पढ़ने और उपलब्ध Linux
जाँच चलाने के लिए हैं।

## 1. बिना कमांड चलाए फ़ाइलें पढ़ें

1. [परियोजना का GitHub पेज](https://github.com/knewnothing-git/gpusion-driver) खोलें।
2. `README.md` में परिचय और `CONTRIBUTING.md` में योगदान की जानकारी पढ़ें।
3. फ़ाइलें डाउनलोड करने के लिए **Code → Download ZIP** चुनें और ZIP निकालें।
   केवल दस्तावेज़ पढ़ने के लिए Git, Visual Studio या Administrator अधिकार
   आवश्यक नहीं हैं।
4. इंस्टॉलर की उपलब्धता देखने के लिए
   [Releases](https://github.com/knewnothing-git/gpusion-driver/releases) पेज देखें।
   डाउनलोड करने योग्य, समर्थित रिलीज़ न हो तो इंस्टॉलेशन के लिए यहीं रुकें।

## 2. Git से परियोजना डाउनलोड करें

कोड में योगदान देना हो तो पहले Git इंस्टॉल करें। सामान्य Terminal या
PowerShell खोलें; इन चरणों के लिए Administrator मोड आवश्यक नहीं है।

```sh
git --version
git clone https://github.com/knewnothing-git/gpusion-driver.git
cd gpusion-driver
git rev-parse --short HEAD
git status --short
```

`git rev-parse` आपके डाउनलोड किए गए संस्करण की पहचान दिखाता है। नई, बिना
बदली हुई कॉपी में `git status --short` का आउटपुट खाली होना चाहिए।
यदि `gpusion-driver` नाम का फ़ोल्डर पहले से है, उसे हटाने के बजाय अलग जगह
डाउनलोड करें।

## 3. वैकल्पिक: Linux पर संकलन-जाँच

यह भाग डेवलपर के लिए है। Linux वातावरण में CMake **3.20 या नया**, GCC और
Ninja उपलब्ध होने चाहिए। यह परियोजना की मौजूदा CI प्रक्रिया का संकलन वाला
भाग है; **इससे इंस्टॉल करने योग्य Windows ड्राइवर नहीं बनता**।

परियोजना के मुख्य फ़ोल्डर में चलाएँ:

```sh
cmake --version
gcc --version
ninja --version
cmake -S . -B build -G Ninja -DCMAKE_C_COMPILER=gcc -DCMAKE_BUILD_TYPE=Debug
cmake --build build --parallel 2
```

पहला CMake चरण बिल्ड की तैयारी करता है; दूसरा C फ़ाइलें संकलित करता है।
सफल होने पर `build/libgpusion_syntax_check.a` बनता है। यह Linux जाँच की
स्टैटिक लाइब्रेरी है, Windows का `.sys` ड्राइवर नहीं।

जाँच सफल होने से वास्तविक Windows इंस्टॉलेशन, GPU पहचान या AI inference
सफल होने का प्रमाण नहीं मिलता। मौजूदा CMake फ़ाइल में कोई CTest टेस्ट
पंजीकृत नहीं है; केवल `ctest` चलाकर कार्यात्मक परीक्षण का दावा न करें।

## 4. Windows ड्राइवर विकास की तैयारी

[CONTRIBUTING](../CONTRIBUTING.md) में Windows 10/11 (64-bit), Visual Studio
2022 का C++ desktop workload और Windows Driver Kit (WDK) बताए गए हैं।
Python 3.10+ को भविष्य के टूल और बेंचमार्क के लिए सूचीबद्ध किया गया है।

इन टूल को इंस्टॉल करने से गायब बिल्ड फ़ाइलें नहीं मिलेंगी। पहले परियोजना
में वास्तविक Windows बिल्ड परियोजना और बिल्ड/इंस्टॉल निर्देश उपलब्ध होने
की पुष्टि करें। केवल यह गाइड पढ़ने या Linux जाँच करने के लिए Windows
test-signing, Secure Boot या अन्य सुरक्षा सेटिंग बदलने की ज़रूरत नहीं है।

Windows इंस्टॉलेशन की प्रक्रिया उपलब्ध होने पर रिलीज़ के निर्देश अपनाएँ।
अभी Device Manager में “GPUsion Virtual Adapter” दिखने को इन चरणों का
अपेक्षित परिणाम न मानें।

## 5. सामान्य समस्याएँ

| समस्या | अगला कदम |
|---|---|
| `git` कमांड नहीं मिलती | Git इंस्टॉल करके Terminal दोबारा खोलें, या ZIP वाला तरीका अपनाएँ। |
| `cmake`, `gcc` या `ninja` नहीं मिलता | अपने Linux वितरण के पैकेज मैनेजर से संबंधित टूल इंस्टॉल करें, फिर उसका संस्करण जाँचें। |
| CMake को `CMakeLists.txt` नहीं मिलता | पुष्टि करें कि Terminal `gpusion-driver` के मुख्य फ़ोल्डर में खुला है। |
| बिल्ड फ़ोल्डर में generator mismatch आता है | मौजूदा फ़ोल्डर मिटाने के बजाय दोनों CMake कमांड में `build` की जगह नया नाम, जैसे `build-hindi`, दें। |
| `build.ps1` या `install.ps1` नहीं मिलता | इस संस्करण में ये फ़ाइलें मौजूद नहीं हैं; यह आपके कंप्यूटर की खराबी नहीं है। |
| C संकलन में त्रुटि आती है | पहली त्रुटि, चलाया गया कमांड और कमिट पहचान सुरक्षित करें; सफलता का दावा न करें। |
| लाइब्रेरी बन गई, लेकिन AI ऐप में GPU नहीं दिखता | Linux जाँच ड्राइवर इंस्टॉल नहीं करती; Windows और inference वाले हिस्से अभी अलग, अधूरे काम हैं। |

## 6. सहायता या योगदान

पहले [Issues](https://github.com/knewnothing-git/gpusion-driver/issues) में
समान समस्या खोजें। नई रिपोर्ट में ऑपरेटिंग सिस्टम, कमिट पहचान, टूल के
संस्करण, चलाया गया कमांड और त्रुटि का पाठ दें। लॉग साझा करने से पहले निजी
पाथ, टोकन और दूसरी निजी जानकारी हटा दें। हिंदी और अंग्रेज़ी, दोनों में
योगदान का स्वागत है।

दस्तावेज़ सुधारने के लिए GitHub पर **Fork** से अपनी कॉपी बनाएँ, उसमें नई
शाखा पर बदलाव करें और मूल परियोजना को pull request भेजें। विस्तृत प्रक्रिया
[CONTRIBUTING](../CONTRIBUTING.md) में है।
